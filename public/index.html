사용법

사진이나 텍스트 속 수식을 한글(HWP)에서 바로 고칠 수 있는 수식 개체로 바꿔 주는 도구예요. 만든 .hwpx 파일을 열면 수식이 실제 수식으로 들어가 있어요.

1무료로 시작하기 — API 키 없이무료
  1. 왼쪽 문제 입력 패널의 수동 입력 탭을 엽니다. (머리글 모델 단추 → AI 연동 없이 이용을 눌러도 바로 열려요)
  2. Gem 에서 텍스트 생성을 눌러 전용 Gem 을 열고 문제 사진이나 요청을 넣습니다. Gem 화면에서 Pro 모델을 고르면 수식이 더 정확해요.
  3. Gem 이 준 텍스트를 복사해 입력 칸에 붙여 넣고 박스 만들기(또는 Ctrl+Enter).
  4. 내 Gem 을 따로 만들고 싶다면 Gem 프롬프트 복사로 지침을 복사해 쓰세요.
2AI 로 바로 만들기 — API 키 연동API 키
  1. 머리글 모델 단추에서 Gemini · ChatGPT · Claude 중 하나를 고르고, 뜨는 창에 키를 붙여 넣어 저장합니다. 키는 이 브라우저에만 저장돼요.
  2. Gemini 는 무료 키 / 유료 키 중 하나를 꼭 골라야 저장돼요. 무료 키는 한도 안에서 0원, 유료 키는 쓴 토큰만큼 결제돼요.
  3. AI 입력 탭에 문제 사진을 끌어 놓거나 Ctrl+V 로 붙이면 글자와 수식을 읽어 박스로 만들어요. 여러 장이면 차례로 읽고, 이 장 넘기기 · ■ 중지로 멈출 수 있어요.
  4. AI로 새 문제 생성 칸에 원하는 내용을 적고 생성하기를 누르면 체크한 박스를 참고해 새 문제를 만들어요.
  5. 박스마다 AI 단추로 "더 어렵게 바꿔줘"처럼 그 문제만 다시 쓰게 할 수 있어요.
3박스 보기 · 정리하기
  • 박스 머리의 편집 · 미리보기 · 한글 문법으로 보기를 바꿔요. 보라 알약이 지금 보고 있는 보기예요. 한글 문법은 한/글 수식편집기에 그대로 붙여 넣을 수 있는 글이에요.
  • 박스 머리띠(⠿)를 끌거나 ↑↓ 로 순서를 바꾸고, 체크한 박스만 변환돼요. 여러 개를 고르면 하나로 합치기 · 복제 · 삭제를 한꺼번에 할 수 있어요. 전체 선택(Ctrl+A)으로 모두 고르고 Esc로 풀어요. 체크 상자를 누른 뒤 다른 체크 상자를 Shift+클릭하면 그 사이가 한꺼번에 골라져요.
  • 박스 나누기: 미리보기에서 줄과 줄 사이에 마우스를 올리면 ✂ 여기서 나누기가 나와요. 눌러서 표시한 뒤 박스 아래의 박스 N개로 나누기를 누르면 표시한 곳마다 따로 박스가 돼요. 문항 번호가 여러 개인 박스는 문항 번호마다 나누기 표시 한 번으로 표시할 수 있어요.
  • 수식에 흔한 실수(짝이 없는 $, 중괄호 짝, 미리보기에서 깨지는 수식)가 있으면 박스 위에 ⚠ 띠가 뜨고, 누르면 그 자리로 가서 고칠 수 있어요. 변환할 때도 한 번 더 알려 줘요.
  • 🔍 찾아 바꾸기(Ctrl+H)로 모든 박스의 글자를 한 번에 바꿔요 (예: [4점] → [3점]). 정렬 ▾ → 문항 번호 다시 매기기로 "1. 2. 3."을 차례대로 다시 붙여요.
  • 정렬로 출처별 · 길이순 · 역순 정리, ↶ ↷(Ctrl+Z)로 되돌리기.
4hwpx 로 변환 · 저장
  • 수식 글꼴(학교시험 HancomEQN · 평가원 HyhwpEQ)과 파일 이름을 정하고 hwpx로 변환을 누르면 체크한 박스가 한 파일로 내려받아져요.
  • 머리글 오른쪽 ＋ 새 문서로 탭을 늘리면 탭마다 따로 hwpx 파일을 만들어요. 탭 이름은 파일명 칸과 같고, 탭을 두 번 누르면 이름을 바꿀 수 있어요.
  • 작업은 이 브라우저에 자동 저장돼요. 다음에 열면 이어서 하기로 그대로 돌아와요.
  • 머리글 파일 ▾ → 전체 저장 (JSON)으로 모든 문서를 파일로 남기고, JSON 열기로 다시 불러와요 (다른 컴퓨터로 옮길 때).
